# Company Site — Next.js + React + Tailwind

Migración del sitio a Next.js App Router, React y Tailwind CSS. Todo el sitio está en español.

## Estructura
- `app/page.tsx`: home
- `app/cabanas/page.tsx`: subpágina de Cabañas
- `app/globals.css`: estilos globales y tokens
- `components/site-header.tsx`: header compartido
- `components/site-footer.tsx`: footer compartido
- `components/hero-art.tsx`: arte reutilizable de los heroes

## Ejecutar
```bash
npm install
npm run dev
```
